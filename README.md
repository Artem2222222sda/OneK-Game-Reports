# Bug reports for games from developer One K
This is the **official repository** created for reporting various bugs and issues in the game from the developer OneK.

# Why are we moving here?
We decided to move here to make it easier for people experiencing issues with the game to report them, and also to provide the ability to attach:
* Photos & Screenshots
* Videos & Screen recordings
* Log files (`.txt`, `.log`, etc.)

Old reports will remain in Google Sheets and will be accessible via this [link](https://docs.google.com/spreadsheets/u/0/d/19_BG-KM4E3caR9ODLoeF9YE8xWIwCC4Z6AFIl71QO4o/htmlview).

##  How to report a bug?
To submit a new bug report, follow these simple steps:

1. **Go to Issues:** Click on the [Issues](../../issues) tab at the top of this page.
2. **Create New Issue:** Click the green **"New issue"** button.
3. **Describe the Bug:** Provide as much detail as possible:
   * **What happened:** A short description of the problem.
   * **Steps to reproduce:** How can we find this bug ourselves? (e.g., 1. Open menu, 2. Press start, 3. Game crashes).
   * **Your system info:** Game version, OS (Windows, Android, etc.), and hardware specs if relevant.
4. **Attach media:** Simply drag and drop your screenshots, videos, or log files directly into the text box.
5. **Submit:** Click **"Submit new issue"**.

## Guidelines and Rules
* **Search before posting:** Please check existing posts to ensure your issue hasn't already been reported. If a post already exists, you can leave a comment on it instead of creating a duplicate.
* **Be respectful:** Treat other community members and the developers with respect.
* **One issue per post:** If you have found multiple unrelated issues, please create a separate post for each one.
